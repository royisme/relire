Relire 围绕“精读”设计：在同一篇文章中，把词汇、语法、发音和复习串起来，而不是在多个工具之间反复切换。

01 · 阅读

02 · 理解

重点做好阅读与发音。

Relire 不试图取代一整套法语课程，而是把真实文本阅读过程中最常连在一起的两个任务——理解与发音——做深。

常见问题

开始之前。

Relire 尽量保持简单：一个浏览器、需要 AI 功能时配置自己的 Key，再加上你真正想读的法语文本。

Relire 免费吗？

是。项目采用 MIT License 开源。AI 功能使用你自己的 Gemini API Key，因此相关额度与费用由你自己的提供方账号决定。

需要注册账号吗？

不需要 Relire 账号。文章、生词和进度保存在你的浏览器中。

没有 API Key 可以做什么？

仍然可以打开应用、阅读示例或自己导入的文本，并使用已经保存在本地的学习数据。AI 解析、语音生成和发音评测需要配置 Key。

这是官方 TCF Canada 备考工具吗？

不是。Relire 是独立的法语阅读与发音学习工具。备考时仍应结合官方考试信息、模考题和教师指导。

可以看源码或者反馈问题吗？

可以。完整源码、架构说明和 Issue tracker 都在 GitHub。
