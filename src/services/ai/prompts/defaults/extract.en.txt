Exercise types (use these type IDs exactly):
- WORD_TRANSFORM: change a word, for example feminine to masculine (femme -> mari/homme, étudiante -> étudiant).
- FILL_BLANKS: complete a dialogue or a sentence, with the gap marked [___].
- GENDER_CHECK: choose Masculin or Féminin (or Masculin / Féminin / Masculin ou féminin for professions).
- ODD_ONE_OUT: cross out the outlier in a list (Barrez l'intrus).
- MATCH_PAIRS: match questions with their responses.
- DIALOGUE_ORDER: put the dialogue sentences in a logical order.
- CHOICE_SELECT: choose the correct word from the choices written in the prompt as {opt1|opt2}.
- SENTENCE_BUILD: write complete sentences from a business card or from cues.
- READING_CLOZE: a reading passage with an information card (fiche de lecture) or with cloze blanks.
- NUMBER_DICTATION: French numbers written in letters, or 10-digit French telephone numbers.
- OPEN_QA: formulate an open question (Trouvez la question), translate, or write a short text.

Fields (the app sends the exact schema):
- materialTitle: the title of the lesson or of the extracurricular test. Leave it out when the source has none.
- warnings: problems you noticed, such as illegible text or an unclear layout. Empty when there are none.
- units: the exercise units. Empty when the source has no questions.
- Each unit has: id (unique in the draft, such as u1), section (GRAMMAIRE, VOCABULAIRE, CONJUGAISON, COMPRENDRE or EXTRA), unitNumber (a positive whole number), subPart (A or B, when the source uses them), title (French), instruction (English), example (when the source gives one), isExtracurricular (true for material from outside the workbook), readingPassage (title, content and English translation, when the unit reads a passage; title and translation may be left out), type (one of the exercise types above), grammarTags (the tags its items use, at least one), and items.
- Each item has: id (unique in its unit), itemNumber (a number, or text such as "a"), type (only when the item differs from its unit's type), prompt (blanks as [___]; choices as {a|b} for CHOICE_SELECT), secondaryPrompt (when present), audioText (the French text to read aloud for dictation or numbers), options (when the item has choices or checks; none of them blank), expectedAnswer (a string, an array of strings for several blanks, or null), printedAnswer (only an answer literally printed in the source, otherwise null), acceptableAnswers, explanation (a brief grammar explanation in English), grammarTag (exactly one tag from the list below), and blockers (what is missing for the item to be used, such as audio, a figure, options or context; empty when nothing is missing).

Answer shapes (the app checks these before a unit can be practised):
- WORD_TRANSFORM, SENTENCE_BUILD, OPEN_QA, NUMBER_DICTATION: expectedAnswer is one string.
- FILL_BLANKS, READING_CLOZE: one string for a single [___]; an array with one string per blank, in order, when the prompt has several.
- CHOICE_SELECT: the prompt holds one {a|b} group per choice. expectedAnswer is the chosen option copied exactly from its group: a string for one group, otherwise an array with one option per group, in order.
- GENDER_CHECK, ODD_ONE_OUT: options lists the choices, and expectedAnswer is exactly one of them.
- MATCH_PAIRS: options are the answer lines, each starting with its own letter ("a - ..."); expectedAnswer is the letter of the right line.
- DIALOGUE_ORDER: options are the dialogue lines, each starting with its own letter; expectedAnswer is an array of those letters in the right order, each used once.

Grammar tags (use the ID exactly as written; each item gets exactly one):
- Nouns and determiners: gender-number, articles, partitive-quantity, possessive-demonstrative
- Adjectives and adverbs: adjective-agreement, adjective-position, comparison, adverbs
- Verbs, forms: present, passe-compose, imparfait, plus-que-parfait, future, conditional, subjunctive, imperative, pronominal-verbs, passive
- Verbs, use: tense-choice-past, past-participle-agreement, hypothesis-si, reported-speech, infinitive-gerund
- Pronouns: subject-object-pronouns, y-en, relative-pronouns, other-pronouns
- Sentence: negation, questions, prepositions, connectors, word-order
- Skills: numbers-time, vocabulary-usage, reading-comprehension, listening-dictation, written-expression

Choose the tag for the grammar point an item tests, not for its exercise type. A question about the meaning of a text uses reading-comprehension. Numbers and times use numbers-time; dictation of words and sentences uses listening-dictation.
