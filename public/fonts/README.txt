Bundled fonts

These files are the unmodified latin-subset variable builds that Google Fonts serves, bundled so the app never requests fonts from Google. Each font is licensed under the SIL Open Font License 1.1; the licence text for each ships next to it.

- source-serif-4.woff2, source-serif-4-italic.woff2: Source Serif 4, https://github.com/adobe-fonts/source-serif (OFL-source-serif-4.txt)
- public-sans.woff2: Public Sans, https://github.com/uswds/public-sans (OFL-public-sans.txt)
- fira-code.woff2: Fira Code, https://github.com/tonsky/FiraCode (OFL-fira-code.txt)
