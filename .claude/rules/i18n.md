# Translation rules

- Add every key to **both** `locales/en.json` and `locales/zh.json` in the same change; plural and placeholder forms must match.
- Model, voice and level display names are keys too (`models.*`, `voices.*`, `levels.*`, `providers.*`).
- i18next interpolates `{{…}}`; to show literal braces, pass them as variables.
- Remove keys you stop using. Search for the full key in `src/` first (a key may still be used by another screen).
- Chinese copy: plain Chinese, no French parentheticals, no platform-specific wording.
- `bun run i18n:check` must pass (CI runs it).
