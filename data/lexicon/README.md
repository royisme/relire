# The lexicon data

`lexicon.json` is generated from Morphalou 3.1 by `scripts/lexicon/build.ts` and is never edited by hand; `NOTICE.md` states the licence (LGPL-LR), the rebuild recipe and how to replace the file. `lemmas.txt` is the allowlist the file is built from. The counts, checked against the committed file by `bun scripts/lexicon/build.ts --check`:

5,022 entries and 42,593 forms.
